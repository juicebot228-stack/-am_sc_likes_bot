# Бот: лайки SoundCloud -> Telegram-канал

## Запуск
1. Создай на github.com новый репозиторий (можно приватный) и загрузи в него все файлы
   из этой папки, включая скрытую папку `.github`.
2. В репозитории: Settings -> Secrets and variables -> Actions -> New repository secret.
   Имя `BOT_TOKEN`, значение — токен от @BotFather.
3. Убедись, что бот добавлен админом в канал @am_sc_likes с правом публикации.
4. Вкладка Actions -> "Post SoundCloud likes" -> Run workflow (первый ручной запуск).
   Первый запуск ничего не постит, он запоминает текущие лайки.
5. Поставь новый лайк в SoundCloud, снова нажми Run workflow: трек должен появиться в канале.
   Дальше всё идёт само каждые 30 минут.

## Настройки (в .github/workflows/post.yml)
- POST_OLD: "true" -> выложить и старые лайки (от старых к новым).
- MAX_PER_RUN: сколько треков за один запуск. При 30 минутах и значении 1 это 2 трека в час.

## Важно
- Лайки в SoundCloud должны быть публичными.
- GitHub отключает расписание, если в репозитории 60 дней нет активности. Коммиты бота обычно её
  поддерживают, но если посты встали, нажми Run workflow вручную.
- Расписание у GitHub неточное, задержки в несколько минут нормальны.
